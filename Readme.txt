# GenAI Hackathon – Voice ↔ Text Pipelines

> **Real-time speech and text processing with Generative AI**  
> Convert voice to text, text to voice, and integrate LLM workflows to build intelligent voice-enabled applications.

---

## 🚀 Overview

This project was built for a hackathon to demonstrate end-to-end **voice–text–voice** capabilities powered by Generative AI.

It contains:
- **Voice → Text (STT):** Capture audio input, transcribe it to text using Speech-to-Text models.
- **Text → Voice (TTS):** Generate natural-sounding speech from text responses.
- **Generative AI Integration:** Send transcribed text to an LLM (e.g., OpenAI/Anthropic) and receive contextual replies.
- **Modular Architecture:** Python backend for AI pipelines, JavaScript frontend for user interaction.
